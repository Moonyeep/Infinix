# Índice do pacote

- `QUICKSTART_AGENT.md`: tutorial de instalação e uso.
- `Start_Agent.bat`: launcher Windows com agente habilitado.
- `Start_Roblox.bat`: launcher Windows opcional que habilita o backend Roblox.
- `Start_Agent.command`: launcher macOS/Linux com agente habilitado.
- `start_agent.sh`: launcher Linux.
- `bridge.py`: bridge WebSocket/MCP e canal `agent.*`.
- `agent_core/`: política, workspace, ferramentas, sessões, checkpoints, loop e providers.
- `zeroscript-extension/`: extensão Chrome/Edge Manifest V3.
- `self_improve.py`: uma rodada segura de autoaperfeiçoamento.
- `schedules/`: modelos de agendamento semanal.
- `THIRD_PARTY_NOTICES.md`: atribuições e licenças das referências open source.
- `MY_BROWSER_RESEARCH.md`: resultado da pesquisa sobre Manus My Browser, Nanobrowser e AIPex.
